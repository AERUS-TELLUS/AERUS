# **Securing_Aircraft** *(Avaliação Conjunta - Pós-Voo)*

## **Objetivo**: Finalização das operações e segurança da aeronave.

---

### **Itens de Verificação**

- **Desligamento de Sistemas Não Críticos**
  - [ ] Câmeras, sensores secundários e outros sistemas desativados.
- **Verificação Visual Pós-Voo**
  - [ ] Inspeção visual para danos ou anomalias (asa, fuselagem, trem de pouso, etc.).
- **Check de Fixações**
  - [ ] Todas as fixações (parafusos, porcas, etc.) estão seguras.
- **Monitoramento de Temperatura**
  - [ ] Temperatura de componentes críticos: **50°C**. 
- **Confirmação de Desativação de Sistemas**
  - [ ] Todos os sistemas desativados corretamente.
- **Verificação de Trem de Pouso**
  - [ ] Trem de pouso travado (se aplicável) e sem danos.
