# **Taxi** *(Avaliação Combinada - Opcional)*

## **Objetivo**: Verificação durante movimento no solo.

---

### **Itens de Verificação**

- **Verificação de Freios** *(se aplicável)*
  - [ ] Testar freios: resposta imediata e sem arrastos.
- **Navegação no Solo**
  - [ ] Confirmar que o UAV responde a comandos de direção.
  - [ ] Velocidade máxima durante taxi: **10 nós**. 
- **Verificação de Obstáculos**
  - [ ] Usar câmera/sensores para confirmar rota livre.
- **Monitoramento de Bateria**
  - [ ] Nível de carga: **90%** (mínimo para taxi).
- **Confirmação de Modo de Taxi**
  - [ ] Sistema no modo **"Taxi"** ativo.
