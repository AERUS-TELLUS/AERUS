# **Shutdown** *(Avaliação Manual)*

## **Objetivo**: Desligamento seguro do sistema.

---

### **Itens de Verificação (Ordem Obrigatória)**

1. **Desligamento de Sistemas de Voo**
  - [ ] Autopiloto desativado.
  
     \[ \] GPS e IMU desligados.
2. **Desconexão de Baterias Principais**
  - [ ] **Último passo**: Desconectar as baterias principais *(após confirmar que todos os sistemas estão desativados)*.
3. **Verificação Final de Segurança**
  - [ ] UAV seguro para manutenção ou armazenamento.
4. **Registros de Voo**
  - [ ] Dados de telemetria e logs baixados e armazenados.
5. **Checklist de Manutenção Pós-Voo**
  - [ ] Anotar issues ou manutenções necessárias para a próxima operação.
