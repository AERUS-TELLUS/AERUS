# **Parking** *(Avaliação Combinada)*

## **Objetivo**: Verificação durante o taxi para o hangar.

---

### **Itens de Verificação**

- **Verificação de Rota para Hangar**
  - [ ] Rota livre de obstáculos (**validação visual ou por sensores**).
- **Monitoramento de Bateria**
  - [ ] Nível de carga: **20%** (mínimo para taxi até hangar).
- **Verificação de Sistemas**
  - [ ] Todos os sistemas operacionais após o taxi.
