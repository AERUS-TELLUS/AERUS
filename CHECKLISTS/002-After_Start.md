# **After_Start** *(Avaliação Conjunta do Sistema com Validação do Operador)*

## **Objetivo**: Verificação de sistemas após energização.

---

### **Itens de Verificação**

- **Inicialização do Sistema de Voo**
  - [ ] Autopiloto inicializado corretamente.
  - [ ] GPS e IMU com sinais estáveis.
- **Teste de Comunicação**
  - [ ] Conexão com TELLUS. 
  - [ ] Telemetria transmitindo dados em tempo real.
- **Verificação de Sensores**
  - [ ] Leituras iniciais validadas (altímetro, velocímetro, bússola, etc.).
- **Teste de Servos e Atuadores**
  - [ ] Movimentar superfícies de controle via comando remoto.
  - [ ] Confirmar resposta imediata e sem ruídos.
- **Verificação de Luzes de Navegação** *(se aplicável)*
  - [ ] Luzes de navegação e anti-colisão funcionando.
- **Check de Calibração**
  - [ ] IMU calibrado (erro **0.5°**).
  - [ ] Bússola calibrada (sem interferências magnéticas).
