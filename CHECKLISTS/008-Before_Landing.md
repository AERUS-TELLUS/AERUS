# **Before_Landing** *(Avaliação Autônoma)*

## **Objetivo**: Preparação para a fase de pouso.

---

### **Itens de Verificação**

- **Verificação de Altitude**
  - [ ] Altitude adequada para iniciar descida: **50-100m** (ou conforme plano).
- **Validação de Trajetória de Descida**
  - [ ] Trajetória alinhada com a pista/área de pouso (**erro 1m**).
- **Check de Sistemas de Pouso**
  - [ ] Trem de pouso: **estendido e travado** (se aplicável).
  - [ ] Freios: **prontos para acionamento** (se aplicável).
- **Verificação de Condições Meteorológicas**
  - [ ] Vento: **15 nós**, sem rajadas.
  - [ ] Visibilidade: **3 km**. 
- **Monitoramento de Obstáculos**
  - [ ] Sensores detectam área de pouso livre (**raio de 50m**).
